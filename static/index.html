从当前脚本以外的已保存脚本选择入口节点，入口可达的全部节点与内部选项连接会被一次性复制到当前画布； 节点和选项会重新生成 ID，内部跳转引用统一重写，环路或多路径汇合也只复制一次，原本无效或未连接的目标保持未连接。 新分支按原相对坐标放在当前视野附近，不会覆盖当前起始节点，整次移植计为一次撤销。

📈 分享作答路径漏斗✕

选择一个已创建的只读分享快照，服务端只读取该快照下的分享作答会话（编辑器预览与其他快照不计入）， 按每次作答记录的原脚本节点 ID 与选项 ID 顺序构建路径前缀树：环路中重复选择同一选项仍保留在不同深度，不会按节点合并。 每个前缀显示到达会话数、在此停止的未完成数、在此完成数与相对父路径的到达比例； 节点/选项文案取自快照原文（受访者当时看到的文字），后续改稿不影响这里。点击任一行可列出到达该前缀的会话 ID。

只读分享链接✕

链接打开的是生成分享时脚本的只读快照（受访者视角），后续编辑不影响已分享内容。

🕒 作答开放规则（仅限制新建作答，UTC 时间）

三项可任意组合，留空即不限制：开始时间含该时刻、截止时间不含该时刻； 上限为正整数，指该快照已创建的作答会话数。规则只拦截新建会话—— 受访者已开始的会话仍可继续作答、撤回与续答，编辑器「▶ 运行预览」不受任何限制。 保存时会校验开始必须早于截止、上限必须为正整数。
