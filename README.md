# 分支访谈脚本编辑器（Branch Interview Script Editor）

用 **Python FastAPI + SQLite + 原生 JavaScript** 构建的可视化分支访谈脚本编辑器。
在画布上创建问题节点、用条件选项连接成有向流程图，系统实时检测 **环路 / 孤立节点 / 未覆盖出口** 并在画布上标记；
保存后可进入「运行预览」按回答跳转并记录完整路径；支持脚本 JSON 导入导出与只读分享链接，
只读分享页支持**撤回上一答**（回到上一题改选，环路中只撤回最后一次）与凭**一次性续答令牌**暂停后恢复原会话继续作答；编辑器还可为某个**分享快照**单独开启**邀请制**，
批量生成随机邀请码并查看已用 / 未用数量，受访者须输入邀请码才能在该快照开始新会话；也可为已创建的快照设置**作答开放规则**（UTC 开始时间含、截止时间不含、新建会话正整数上限），
随时查看**已创建会话数与当前开放状态**（开放中 / 未开放 / 已截止 / 已满），未设置的项目不限制；规则只拦截新建作答，已开始的会话继续作答 / 撤回 / 续答不受影响，编辑器预览也始终不受限制。
每个脚本还可维护**一个目标语言的译文**（按节点/选项 ID 编辑标题、正文与选项文案），原文改动后译文自动标为**待复核**，
创建只读分享时可选择该语言、把当时**已复核**的译文冻结进快照；作答页逐字段展示译文，缺失或待复核字段回退原文，
选项 ID、跳转与作答记录始终沿用原脚本。编辑器还可选择某个**已创建的分享快照**查看其作答会话，按每次作答选择的
**原脚本节点 ID + 选项 ID 顺序**构建「**分享作答路径漏斗**」（路径前缀树）：到达会话数、在此停止的未完成数、
在此完成数与相对父路径的到达比例一目了然，环路中重复选择同一选项仍保留在不同深度，点击任一前缀即可列出对应会话 ID。

## 一条命令启动

```bash
docker compose up -d --build
```

启动后打开浏览器访问：

- 编辑器主页（Web）： **http://localhost:8000**
- 只读分享页（Web）： http://localhost:8000/share.html?token=分享令牌
- API 文档（Swagger）： http://localhost:8000/docs （业务接口统一在 `http://localhost:8000/api/...`，端口均为 **8000**）

停止：`docker compose down`（数据保留在命名卷中；加 `-v` 可同时删除数据卷）。

> 首次启动会创建一张内置示例脚本（包含一条演示环路），方便立即体验校验标记。

## 端口与配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 宿主机端口 | `8000` | 在 `docker-compose.yml` 的 `ports` 中修改，例如 `"9000:8000"` |
| `DB_PATH` | `/data/editor.db` | SQLite 数据库文件路径（容器内），已挂载到命名卷 `editor-data` 持久化 |
| 数据卷 | `editor-data` | 命名卷，容器删除后脚本、分享快照、作答会话与续答令牌仍保留 |
| 重启策略 | `unless-stopped` | 见 compose 文件 |

容器健康检查：每 30 秒请求一次 `GET /api/scripts`。

### 不用 Docker 的本地运行方式

需要 Python 3.11+：

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# 此时数据库默认为项目根目录下的 editor.db；可用环境变量 DB_PATH 覆盖
```

本地运行的访问地址与端口同上：编辑器主页 http://localhost:8000 ，分享页 http://localhost:8000/share.html ，API 文档 http://localhost:8000/docs （基础路径 `/api/...`）。如需换端口，改 `uvicorn --port` 即可（容器部署则改 `docker-compose.yml` 的端口映射）。

## 功能说明

### 画布编辑

- **添加节点**：工具栏「＋ 添加问题节点」，节点支持「问题」和「告知」两种类型；
- **移动 / 平移**：拖动节点标题移动节点，在画布空白处拖动平移画布；
- **连线**：按住选项行右侧的小圆点（port）拖到目标节点松开，即建立「选中该选项 → 跳转目标节点」；
- **编辑**：点击节点在右侧属性栏修改标题、文案、选项文案与跳转目标，可标记「终止节点」和「起始节点」；
- 点击连线可修改跳转目标或删除连线。

### 撤销 / 重做

- 工具栏「↶ 撤销 / ↷ 重做」按钮与快捷键 **Ctrl/Cmd+Z**、**Shift+Ctrl/Cmd+Z**（另支持 Ctrl+Y）共用同一份历史；
- 覆盖节点增删、标题/文案/选项修改、连线增删与跳转目标修改、节点拖动等全部画布编辑；
- 一次节点拖动只记为一条历史；同一输入框内的连续输入自动合并为一条；
- 撤销/重做后画布、右侧属性栏与流程校验标记（环路/孤立/未覆盖出口）同步刷新，未保存徽标按当前内容与保存点的差异实时更新；
- 保存脚本或切换脚本后历史清空，从新的基线重新开始记录。

### 实时校验（客户端实时 + 保存后服务端复核）

| 标记 | 颜色 | 含义 |
| --- | --- | --- |
| 环路（cycle） | **红色** | 节点处于有向环中（Tarjan SCC 检测），可能导致访谈无法走到终点；对应连线也标红 |
| 孤立节点（orphan） | **橙色虚线** | 从起始节点出发不可达（BFS 不可达） |
| 未覆盖出口（uncovered） | **紫色** | 选项没有连接目标（紫色虚线连线/端口），或非终止节点没有任何选项 |

工具栏右侧实时显示各类问题的数量徽标；全部通过时显示「流程校验通过」。

### 运行预览与路径记录

- 保存后点击「▶ 运行预览」，从起始节点开始，按选项逐条跳转；
- 未连接目标的选项不可选；进入终止节点（或无选项节点）时显示「访谈结束」；
- 右侧实时记录完整 **回答路径**（节点顺序 + 每步选择的答案），可随时「重新开始」；
- 路径存储在服务端 SQLite（`runs` 表），刷新后仍可通过 `GET /api/runs/{id}` 查看。

### 分支覆盖统计

按**当前脚本**汇总已保存运行记录（编辑器「运行预览」与只读分享链接作答都会计入）中各选项被选择的次数，用于发现设计了但从未被受访者走到的分支：

- 工具栏「📊 分支覆盖」打开统计面板：运行会话数、已覆盖分支数、分支覆盖率、累计选择次数、走到结束的会话数，并按节点列出每个选项的选择次数条形图；红色行即「从未走过」的选项，点击任一行可直接跳转到对应节点；
- **节点属性区**：每个选项右侧带统计徽标 —— `✓ 已选 N 次` / `⚠ 从未走过 · 0 次`（红底标出）/ `— 未连接，不可选`；选项区下方给出本节点 `已走过 X/Y` 的小结；未选中任何节点时，属性栏底部显示整份脚本的覆盖概览；
- **脚本尚无运行记录时显示空统计**（提示去运行预览/分享，不标红任何选项），不会产生误导；
- 统计基于**上次保存**的脚本与 `runs` 表：刚新增、尚未保存的选项显示「新增 · 保存后统计」；有未保存改动时面板顶部给出提示。关闭运行预览弹窗、保存脚本或点击面板内「↻ 刷新统计」都会重新拉取；
- 未连接目标的选项在运行中不可选，只展示不纳入覆盖率；编辑脚本后已删除节点/选项的历史计数自动忽略；
- 覆盖统计是独立的只读查询，**不影响实时结构校验**（环路 / 孤立 / 未覆盖出口照常即时刷新）。

### 指定选项路线规划

- 工具栏「**🧭 路线规划**」打开规划面板：列出**当前画布**（含未保存修改）中全部已连接目标的选项，勾选 **1～6 个**后点击「开始规划」；
- 服务端以「当前节点 × 已收集勾选选项集合」为状态做 BFS，求从**起始节点**出发、**经过每个勾选选项至少一次**、最终到达**终止节点（含无选项节点）**的**最短选择序列**（以选择次数计）；
- 搜索**允许环路和重复访问节点**，但**标记为终止的节点不可继续选择**；若无可行路线会明确显示**无解**，不返回部分路径；
- 结果按顺序展示每一步的 **节点 → 所选选项 → 目标节点**，勾选选项带 ✓ 标记，终点单独标出；点击任一节点名可将该节点居中定位到画布并选中；
- 规划是只读计算（`POST /api/route-plan`，请求体即当前画布内容，不落库）：**不保存脚本、不生成运行记录、不改变分支覆盖统计**。

### 改稿影响分析

改稿后担心历史作答对不上新画布？工具栏「**🩺 改稿影响分析**」以**当前画布（含未保存修改）**为基准，对本脚本的**运行预览**与**只读分享作答**记录逐条重放核对：

- 服务端从**当前起点**出发，按答卷记录中的**历史选项顺序**逐步重放，逐步核对**跳转目标**，并只返回每个会话遇到的**首个断点**及原因；
- 识别的断点：**起点改变**（`start_changed`）、**节点消失**（`node_missing`）、**选项消失**（`option_missing`）、**跳转改指/改成未连接**（`redirected`）、**提前终止**（`early_terminal`，中途节点变成终点或没有选项）、**已结束答卷不再结束**（`ended_no_longer_terminal`）；
- **未完成答卷只核对已答部分**：暂停点之后的差异不判为受影响，暂停节点本身变成终点也算兼容；已答路径逐步完全匹配即标为**兼容**；
- 面板汇总**作答会话总数、兼容会话数、受影响会话数**（以及预览/分享来源分布与各断点原因数量）；展开任一条记录可查看完整历史路径，断点处高亮并可点击「🎯 定位断点节点」居中定位到画布（节点已删除时提示无法定位）；
- 每次打开面板或点击「↻ 重新分析当前画布」都会即时重放，因此不必先保存；分析期间画布又被改动时会提示结果可能已过期；
- 分析是**只读计算**（`POST /api/scripts/{id}/impact`，请求体即当前画布内容）：**不保存脚本、不改写作答记录、不改变分支覆盖统计**。

### JSON 导入 / 导出

- **导出**：下载形如 `脚本名.json` 的文件，格式为 `{"format":"branch-interview-script","version":1,"name":...,"content":...}`；
- **导入**：支持上述导出格式，也支持直接导入 `{"start_node_id":...,"nodes":[...]}` 的裸 content 对象；
- 内容经过 Pydantic 校验，格式非法时返回 400 与错误信息。

### 跨脚本移植分支

操作入口：编辑器工具栏「**🔀 跨脚本移植**」按钮（在「＋ 添加问题节点」与「↶ 撤销」之间）。在弹窗中：

1. 选择一份**当前脚本以外**的已保存脚本作为来源（来源列表来自 `GET /api/scripts`，脚本内容按需用 `GET /api/scripts/{id}` 拉取，不新增接口）；
2. 选择来源脚本中的**入口节点**（默认预选来源脚本的起始节点），面板实时显示将复制的节点数、内部连接数与未连接选项数；
3. 点击「移植到当前画布」，入口可达的节点与内部选项连接一次性复制到当前画布。

复制规则：

- 为每个节点、每个选项**重新生成 ID**，并统一重写复制范围内的内部跳转引用；原本无效、未连接，或指向复制范围之外的目标仍保持未连接（`target_id` 置空）；
- 使用带访问标记的广度优先遍历，**遇到环路或多条路径汇合时每个节点只复制一次**，内部选项连接也随节点各自复制一份；
- 新分支保持来源中的**相对坐标**，整体平移到**当前视野中心附近**（并限制在画布范围内），不覆盖原脚本内容，也**不改变当前脚本的起始节点**；
- 整次移植计为**一次撤销操作**（Ctrl/Cmd+Z 可整体撤回），移植完成后立即刷新未保存徽标与结构校验标记（环路 / 孤立 / 未覆盖出口）；移植内容尚未保存时不会出现在分支覆盖统计中，保存后即正常计入。

### 只读分享链接

- 工具栏「🔗 只读分享」，在弹窗中选择**快照语言**（原文或脚本配置的目标语言）后点击「生成分享快照」，
  得到形如 `http://localhost:8000/share.html?token=xxxx` 的链接；
- 分享内容是 **生成时的只读快照**（独立存储），之后继续编辑脚本不影响已分享版本；
- 选择目标语言时，生成时刻**已复核**的译文随快照冻结；选择原文则为纯原文快照；
- 分享页只展示受访者视角：逐题作答（可**撤回上一答**）+ 路径记录，页面带「只读」提示，无任何编辑入口；带译文快照的页面顶部显示语言徽标。
- 弹窗顶部「**管理快照**」下拉框可切换到任一**已创建快照**：查看 / 复制链接、设置**作答开放规则**（UTC 开始 / 截止时间、新建会话上限、已创建会话数与当前开放状态）、管理邀请码；
  新建的快照创建后自动出现在下拉框中。

### 分享作答路径漏斗

工具栏「**📈 分享路径漏斗**」：在弹窗顶部的下拉框中选择某个**已创建的只读分享快照**（按创建时间倒序，附带每个快照的会话数 / 完成数、邀请制与语言标记），
服务端**只读取该快照**下的分享作答会话（编辑器「运行预览」与其他快照的会话一律不计入），并：

- 按每次作答记录的**原脚本节点 ID 与选项 ID 顺序**构建**路径前缀树**（trie）；
- **环路不按节点合并**：在环路中重复选择同一选项仍保留在树的**不同深度**，重复的边会显示「🔁 环路重复」标记；
- 每个前缀显示四项指标：
  - **到达**：走到该前缀的会话数；
  - **停止**：路径恰好在该前缀结束的**未完成**会话数（在此中断）；
  - **完成**：路径在该前缀结束且**走到结束**的会话数；
  - **占父**：到达数 ÷ 父前缀到达数（根前缀无父级，显示「—」）；
- 每条前缀同时展示**快照原文**的「来源节点 —「选项」→ 目标节点」文案，以及灰色的 `节点 ID :: 选项 ID`；
  文案取自**生成快照时冻结的内容**（受访者当时看到的文字），之后继续改稿不会改变这里的标签；
- **点击前缀行**即可在其下方展开「到达该前缀的会话 ID」列表（已完成带 ✓、未完成带 ⏸，悬停可见选择次数与时间）；点击行首小三角可展开/收起子前缀（根层默认展开）；
- **空态**：该脚本还没有任何分享快照、或所选快照尚无作答会话时，都给出明确空态提示，不渲染空树、不编造数字；
- 切换快照即时重建；点击「↻ 刷新漏斗」可拉取最新作答。该查询为**只读**：不生成、不改写作答会话。

> 说明：零次选择的会话（开始后未作答）计入根前缀；进入终止节点（或无选项节点）的作答计为「完成」。

### 多语言译文（按节点/选项 ID）

编辑器工具栏「**🌐 多语言译文**」打开译文面板（按钮上实时显示 `缺 N · 待复核 M`）：

- **一个脚本一个目标语言**：在面板顶部填写语言代码（如 `en` / `ja` / `zh-TW`）与语言名称后保存；
  仅修改名称会保留现有译文，**更换语言代码会清空该脚本已有译文**（避免不同语言混用）；
- **按 ID 编辑**：面板按节点分组列出全部可译字段（节点**标题 / 正文**与每个**选项文案**），
  每个字段显示脚本原文（只读）与译文输入框，失焦自动保存（Ctrl/Cmd+Enter 也可触发）、留空保存即删除译文；
- **状态与计数**：字段状态为 `已复核 / 待复核 / 缺失`，面板顶部显示四类计数，可用「全部 / 仅缺失 / 仅待复核 / 仅已复核」筛选；
  选中节点时右侧属性栏的标题、正文与每个选项旁也有迷你状态标记；
- **原文改动 → 待复核**：保存脚本时服务端按字段重新核对原文哈希——原文变了，对应译文自动置为**待复核**，
  待复核字段不会进入分享快照；在面板中重新核对并保存后恢复**已复核**（把原文改回旧值也会自动恢复）；
- **删除即失效，不套新对象**：删除节点或选项后保存，其译文在同一事务中删除；
  即使以后出现相同 ID 的新对象，旧译文也不会挂到它上面（新字段显示为缺失）；对已删除对象保存译文返回 404；
- **定位字段**：每行有「🎯 定位字段」按钮，关闭面板后自动选中节点、聚焦并高亮对应输入框；
- **分享冻结**：创建只读分享时选择该语言，服务端只把当时**已复核**的译文冻结进快照；
  之后继续翻译或改稿不影响已生成的链接。

#### 作答页如何展示译文

- 逐字段展示：节点标题、正文、选项文案优先用快照中的已复核译文；**缺失或待复核字段自动回退原文**（译文文本悬停可看原文）；
- **选项 ID、跳转关系完全沿用原脚本**：受访者点击的仍是原选项 ID，服务端按原脚本跳转；
- **作答记录沿用原文**：路径记录中的节点标题、每步答案仍保存原文文案，统计与改稿分析不受译文影响；
- 编辑器「▶ 运行预览」始终展示原文（译文只面向只读分享）。

#### 作答开放规则（开放时段与会话上限）

编辑器可为**任意已创建的分享快照**设置 / 清除三项**作答开放规则**（全部按 **UTC** 时间），规则随快照保存、后续随时可改，三项互相独立、可任意组合：

- **UTC 开始时间**（`open_started_at`，**含**该时刻）：早于该时刻不能新建作答，页面显示「⏳ 未开放」与开始时间；
- **UTC 截止时间**（`open_deadline_at`，**不含**该时刻）：到达该时刻起不能再新建作答，页面显示「⛔ 已截止」与截止时间；
- **新建会话上限**（`max_new_runs`，**正整数**）：该快照**已创建的分享作答会话数**达到上限后不能再新建，页面显示「👥 名额已满」及上限数；
- **未设置（留空）的项目不限制**；弹窗中可点「清除全部规则」一键恢复为完全开放。编辑区实时显示**已创建会话数**（如 `3 / 上限 100`）与当前状态徽标
  （🟢 开放中 / ⏳ 未开放 / ⛔ 已截止 / 👥 已满）；保存时服务端校验**开始时间必须早于截止时间**（开始含、截止不含，相等也拒绝）、**上限必须为正整数**、时间必须是合法 UTC 时间，非法时返回 400 且不保存；
- 已创建会话数超过后来调低的上限不是错误：快照直接变为「已满」，不会删除既有会话。

**服务端强约束**：新建分享作答时，在**同一个 SQLite 写事务**（`BEGIN IMMEDIATE`）内先按该快照的 UTC 时间与已有会话数判定资格，再核验 / 消耗邀请码并插入会话；
任一步失败整体回滚——被开放规则拒绝时**不创建会话、也不消耗邀请码**。并发抢最后名额时由写锁串行化，**实际创建数绝不会超过上限**（20 个并发抢 5 个名额只有 5 个成功）。

**不受规则限制的操作**：

- **已开始的会话**仍可继续作答、撤回上一答、重新开始，也可暂停后凭续答令牌恢复（恢复的是已有会话，不是新建；未开放 / 已截止 / 已满期间续答入口照常可用）；
- **编辑器「▶ 运行预览」**始终直接开始，开放规则只面向只读分享的新建作答。

受访者侧：打开分享页即可在入口卡片看到未开放 / 已截止 / 已满的**具体原因**（开始 / 截止显示 UTC 时间与含 / 不含口径，已满显示名额），此时开始新作答的按钮隐藏，但下方「恢复会话」入口保留；
开放中的快照则在入口处显示一行 UTC 开放时段与名额进度（`开始 …（含） · 截止 …（不含） · 名额 3/100`，全未设置时不显示）。若页面在打开后跨过了开始 / 截止时刻或名额被抢光，点击开始时服务端会再次在事务内判定，页面随即刷新为最新原因。

#### 邀请制（分享快照邀请码）

编辑器可以为**某一个分享快照**单独开启邀请制，邀请码只属于该快照：

- **开启与批量生成**：「🔗 只读分享」弹窗底部「🎫 邀请码（邀请制）」区，输入数量（1～500）后点击
  「开启邀请制并生成」，即把该快照切换为邀请制并批量生成随机邀请码；之后可继续「再生成一批」追加，
  不影响既有邀请码；弹窗中实时显示 **总数 / 已用 / 未用** 数量及每个邀请码的状态（点击未用邀请码可复制）。
- **受访者侧**：邀请制快照的分享页入口会要求输入邀请码（页面顶部带「🎫 邀请制」标记），
  也可直接打开带邀请码的链接 `share.html?token=分享令牌&invite=邀请码` 自动填好；
  输入正确即开始一份新的作答，该邀请码当场消耗并与新会话绑定。
- **服务端强约束**（在**同一个 SQLite 写事务**中完成「核验邀请码 → 消耗邀请码 → 创建会话」，任一步失败整体回滚）：
  - 邀请码只属于生成时的那个分享快照，**跨快照使用一律拒绝**（A 快照的码不能在 B 快照用）；
  - 一码仅可使用一次：**重复使用、并发同时使用**只会有一次成功，其余返回 403/409，且**不会新增会话**；
  - 邀请制开启后，不填邀请码无法开始新会话（403）；
  - **公开分享**（未开启邀请制）仍可一键直接开始，编辑器「▶ 运行预览」也始终直接开始，均无需邀请码；
  - **暂停续答不消耗邀请码**：凭原续答令牌恢复的是已有会话（不是新建），邀请制快照下恢复入口照常可用；
  - 「↺ 重新开始」复用原会话，同样不再消耗邀请码。

#### 暂停续答（一次性续答令牌）

受访者可以随时关掉页面、之后再接着答，而不必从头开始：

- **暂停**：作答过程中（任意**未结束**的题目节点）点击「⏸ 暂停并生成续答令牌」，弹窗中可复制
  - **一次性续答令牌**（一串随机字符串），以及
  - **含令牌的续答链接**（`share.html?token=分享令牌&resume=续答令牌`，重新打开即自动填好令牌）。
  令牌只在弹窗中显示一次，请立即复制保存；生成令牌**不会中断作答**，继续作答后再使用令牌会恢复到「使用令牌那一刻」的最新进度。
- **续答**：再次打开**同一个分享链接**，入口处选择「恢复会话」（或直接打开续答链接后确认），即可恢复**原来的会话、当前节点与完整回答路径**，继续作答；不会新建会话，右侧路径记录原样还原，页面顶部会显示恢复提示。
- **服务端约束**（错误信息会在入口处直接展示）：
  - 续答令牌与**所属分享快照**一一绑定，只能在该分享链接中使用，拿去别的分享链接会被拒绝；
  - 令牌**一次性**：恢复成功即刻作废，重复 / 并发再次使用都会返回「令牌已使用」；
  - **已结束**的访谈不能暂停、也不能续答（无需续答，可开始新的作答）；
  - 编辑器「▶ 运行预览」的会话不生成续答令牌（暂停续答仅面向只读分享受访者）。
- 「↺ 重新开始」仍是把**同一个会话**清空回到第一题（历史行为不变）；重新开始后，之前已使用 / 未使用的旧令牌都无法再恢复旧进度。

#### 撤回上一答（分享作答页）

受访者在分享作答页选错或想改选时，不必整份重来：

- **入口**：作答区「↩ 撤回上一答」按钮（与「↺ 重新开始」「⏸ 暂停并生成续答令牌」同一行），
  已产生至少一次选择即显示；**未结束或刚结束**的会话都可撤回——刚走到终点的会话撤回后回到最后一题，可继续作答；
- **服务端语义**（`POST /api/runs/{id}/undo`）：按 `steps` 记录的发生顺序找到**最近一次选择**，
  截断其后的路径并清空该步答案，会话回到提出该选择的题目；**环路中同一节点重复出现时只撤回最后一次**，
  更早经过同一节点的路径原样保留；
- **同一事务**：当前节点、回答路径（steps）与结束状态（finished）在一次 SQLite 写事务中同时更新，
  并同时把该会话**尚未使用的续答令牌全部作废**，避免旧令牌恢复出与路径不符的错误进度（与「重新开始」一致）；
- **硬约束**：零次选择（尚未作答）时拒绝撤回（400）；撤回**不新建会话**（沿用原会话），
  也**不返还已消耗的邀请码**（邀请制快照下邀请码保持已用）；
- **页面同步**：撤回成功后题目卡片与右侧「回答路径记录」按服务端返回一次性刷新。

## 数据模型（SQLite）

- `scripts`：脚本（名称、JSON content、时间戳、`lang_code` / `lang_label` 目标语言）；
- `translations`：脚本目标语言的译文（`script_id` + `lang_code` + `node_id` + `field`（`title`/`text`/`option_label`）+ `option_id`，
  选项字段才有 `option_id`；两个部分唯一索引分别约束节点字段与选项字段）。每行带 `translation`、`source_hash`（译文所对照的原文哈希）
  与据此推导的 `status`（`reviewed` / `pending` 待复核）；保存脚本时在同一事务内对账——删除的节点/选项行立即删除，原文变更的行置为待复核；
- `shares`：只读分享快照（随机 token、快照内容、`invite_only` 是否开启邀请制、`lang_code` / `lang_label`、
  `translations` 为生成时冻结的已复核译文 JSON `{"nodes":{节点ID:{"title","text","options":{选项ID:译文}}}}`、
  `open_started_at` / `open_deadline_at` 为 UTC 开放时段（开始**含**、截止**不含**，NULL 不限制）、`max_new_runs` 为新建会话正整数上限（NULL 不限）；
  当前开放状态由这三列与 `runs` 表中该快照的已有会话数实时推导：`open` / `not_started` / `closed` / `full`）；
- `runs`：预览/分享作答会话（当前节点、步骤 JSON、是否结束）；分支覆盖统计即按脚本聚合该表中每步记录的 `node_id + option_id` 得到，无需额外建表；
- `resume_tokens`：暂停续答令牌（随机 token、所属 `run_id` 与 `share_token`、是否 `used` 一次性标记、时间戳）；令牌与分享快照绑定，恢复成功即原子置为已使用。
- `invite_codes`：分享快照邀请码（随机码、所属 `share_token`、是否 `used`、消耗时绑定的 `run_id` 与时间戳）；每个邀请码只属于一个分享快照，在与新建会话相同的写事务中原子核验并消耗，重复 / 跨快照 / 并发使用均拒绝且不新增会话。

> 数据表均通过 `CREATE TABLE IF NOT EXISTS` 在启动时自动创建/补建；旧库升级时会自动为 `shares` 补建 `invite_only`、
> `open_started_at` / `open_deadline_at` / `max_new_runs` 列、为 `scripts` / `shares` 补建语言与冻结译文列，并创建 `translations` 表，
> **无需手动迁移**，直接 `docker compose up -d --build` 即可（新列默认 NULL，旧快照即「不设任何开放限制」）。

## 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/scripts` | 脚本列表 |
| POST | `/api/scripts` | 新建脚本 |
| GET/PUT/DELETE | `/api/scripts/{id}` | 读取 / 更新 / 删除 |
| POST | `/api/scripts/{id}/validate` | 服务端环路/孤立/未覆盖出口校验 |
| GET | `/api/scripts/{id}/coverage` | 分支覆盖统计：各选项被选择次数 / 从未走过的选项 / 覆盖率 |
| POST | `/api/scripts/{id}/impact` | 改稿影响分析：请求体为当前画布 content，逐条重放预览/分享作答，返回兼容数与受影响会话的首个断点（只读计算，不落库） |
| POST | `/api/route-plan` | 指定选项路线规划：请求体为当前画布 content + 1～6 个勾选选项，返回最短选择序列或无解（只读计算，不落库） |
| GET | `/api/scripts/{id}/export` | 导出 JSON |
| POST | `/api/import` | 导入 JSON |
| PUT | `/api/scripts/{id}/language` | 设置/更换脚本的目标语言（`{"lang_code":"en","lang_label":"English"}`）；更换语言代码会清空该脚本已有译文 |
| GET | `/api/scripts/{id}/translations` | 译文编辑视图：每个可译字段的原文、译文与状态（缺失/待复核/已复核）及汇总计数 |
| PUT | `/api/scripts/{id}/translations` | 保存单个字段译文（按 `node_id`+`field`+`option_id`，自动标记已复核；空译文删除该行；对象已删除返回 404） |
| POST | `/api/scripts/{id}/share` | 生成只读分享链接；请求体可选 `{"lang_code":"en"}`：传入且与脚本目标语言一致时把当时已复核译文冻结进快照 |
| GET | `/api/scripts/{id}/shares` | 列出该脚本已创建的全部分享快照（token、创建时间、邀请制、语言、每个快照的会话数 / 完成数，及开放规则三列与实时 `open_status`）；供路径漏斗选择快照 |
| GET | `/api/share/{token}/funnel` | 该快照的**分享作答路径漏斗**：只读该快照的分享会话，按节点 ID+选项 ID 顺序构建前缀树，返回每前缀的到达 / 在此停止未完成 / 在此完成数、相对父路径比例及到达会话 ID；空样本返回空树 |
| GET | `/api/share/{token}` | 读取分享快照（含 `invite_only`、`lang_code` / `lang_label`、冻结的 `translations`，以及开放规则三列、`run_count` 已创建会话数、`open_status`（`open`/`not_started`/`closed`/`full`）与受访者侧 `closed_reason`） |
| GET/PUT | `/api/share/{token}/rules` | 查看 / 设置该快照的**作答开放规则**：PUT 请求体 `{"open_started_at": UTC 时间(含)或 null, "open_deadline_at": UTC 时间(不含)或 null, "max_new_runs": 正整数或 null}`，全量更新、null 即清除；校验起止顺序（开始须早于截止）、正整数上限与时间格式，返回已创建会话数与实时开放状态 |
| GET | `/api/share/{token}/invites` | 查看该快照邀请制状态与邀请码列表（总数 / 已用 / 未用） |
| POST | `/api/share/{token}/invites` | 开启邀请制并批量生成邀请码（请求体 `{"count": 1～500}`，返回新码与统计） |
| POST | `/api/runs` | 开始预览（`script_id` 直接开始）或分享作答（`share_token`；邀请制快照须同时带 `invite_code`）。分享作答在同一 `BEGIN IMMEDIATE` 写事务内先按 UTC 开始（含）/ 截止（不含）时间与已有会话数判定开放资格（未开放 / 已截止 / 已满返回 403），再核验、消耗邀请码并创建会话；任一失败整体回滚，**不新增会话、不消耗邀请码**；编辑器预览不受开放规则限制 |
| POST | `/api/runs/{id}/choice` | 提交一个选项并跳转 |
| POST | `/api/runs/{id}/undo` | 撤回上一答：按 steps 顺序撤回最近一次选择回到上一题（环路中同一节点只撤最后一次；未结束或刚结束均可用；零次选择 400；当前节点/路径/结束状态在同一事务更新并作废未用续答令牌；不新建会话、不返还邀请码） |
| GET | `/api/runs/{id}` | 查看会话与已记录路径 |
| POST | `/api/runs/{id}/restart` | 重新开始 |
| POST | `/api/runs/{id}/pause` | 仅分享作答会话可用：在当前未结束节点生成**一次性续答令牌**（已结束 / 编辑器预览返回 400） |
| POST | `/api/share/{token}/resume` | 用续答令牌恢复该分享快照下的原会话（原子消费令牌）；令牌不存在 404、属于其他分享 403、已使用 / 访谈已结束 400 |
